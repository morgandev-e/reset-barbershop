# Reset Barbershop — sample site

A mobile-first one-page sample site for Reset Barbershop (Kettle House, Muthangari Road, Lavington, Nairobi).

Built as a free preview by Morgan. Live on GitHub Pages at:
https://morgandev-e.github.io/reset-barbershop/

Services, prices and hours are taken from the shop’s public Welns booking page. Photos are royalty-free stock, not the shop’s own.
